# dDowa Household Latrine survey 2020

This dataset documents household-level sanitation information collected
in the Dowa District. Each row represents an individual household's
sanitation setup, usage patterns, perceptions, and maintenance
behaviors. The goal is to understand the quality, sustainability, and
user satisfaction with existing latrines in rural and peri-urban
communities.

## Usage

``` r
dowalatrinesurvey
```
